# Estudos de Machine Learning

Este repositório reúne estudos, exercícios e experimentos realizados durante a minha jornada de aprendizado em **Machine Learning**. O objetivo é praticar conceitos fundamentais, testar algoritmos, analisar métricas de performance e construir uma base sólida para projetos mais avançados.

---

## 📚 Conteúdo do Repositório

### ▶️ Projeto: `exercicio-01`

Pasta dedicada a um exercício introdutório de Machine Learning, cobrindo todo o fluxo básico:

- Leitura e exploração dos dados  
- Pré-processamento  
- Treinamento de modelos  
- Avaliação por métricas  
- Geração de previsões

**Arquivos principais:**

- `exercicio01.ipynb` – Notebook principal contendo todo o fluxo do exercício  
- `previsao01.csv` – Arquivo com previsões geradas  
- Demais arquivos auxiliares do experimento  

---

## 🚀 Objetivo

Este repositório serve para:
